# 亮点一： 守护进程+多客户端架构
kama-core 守护进程持久运行，kama-tui / kama-cli 作为客户端通过 TCP 连接。
客户端断开不中断 Agent 执行，重连后可恢复订阅

实现细节：
- 传输层：asyncio.start_server + NDJSON framing , 每行一个 JSON-RPC 2.0 消息
- 服务器启动时探测端口，已有守护进程则快速失败，避免双启
- 客户端通过 event.subscribe （支持 glob topic）注册感兴趣的事件，服务器仅推送匹配项

为什么这样设计：TUI 崩溃或者用户关闭终端不会杀死正在执行的 Agent；未来接入 Web 前端而无需修改核心
